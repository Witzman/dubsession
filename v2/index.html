Dubsession v2

A generative dub-techno DJ. Two decks, drawn tracks, and a hand on the stems while it runs.

This page is a placeholder. It exists so the stage is wired before anything needs it — so that the first thing built can be played rather than described. There is no audio here yet.

What this will be

  • A continuous, autonomously generated dub-techno set that does not end
  • Two decks with a beatmatched, phrase-aligned crossfade between them
  • Track requests, inside the one genre
  • Stem mixing — each lane of each deck moved on its own, not just the two deck faders
  • Live sound design while the set runs: filter, echo, delay, reverb, bass, drums — without interrupting generation, playback or the mix

Where it stands

  • The reference DJ machinery is read and written down
  • The architecture is drafted: two decks over one audio context, the transition on two levels — symbolic and acoustic
